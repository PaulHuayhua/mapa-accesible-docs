# Tipos de Usuario

## Visitante

Usuario que entra sin registrarse.

Puede:

- Ver el mapa.
- Buscar lugares.
- Consultar información básica.

No puede:

- Publicar reseñas.
- Subir fotos.
- Guardar favoritos.
- Usar contactos de emergencia personalizados.

## Usuario registrado

Persona con cuenta creada.

Puede:

- Guardar preferencias.
- Valorar lugares.
- Crear reportes.
- Subir fotos.
- Guardar favoritos.
- Configurar contactos de emergencia.
- Usar el botón SOS completo.

## Usuario colaborador

Usuario que aporta información de forma frecuente y confiable.

Puede:

- Confirmar reportes.
- Sugerir correcciones.
- Aportar detalles más completos.

Este rol puede asignarse automáticamente por reputación o manualmente por moderadores.

## Comercio o institución

Cuenta asociada a un lugar, empresa o entidad.

Puede:

- Reclamar la ficha de un lugar.
- Actualizar información de accesibilidad.
- Responder comentarios.
- Publicar fotos oficiales.
- Solicitar revisión o certificación futura.

## Moderador

Usuario encargado de revisar contenido.

Puede:

- Revisar reportes.
- Ocultar comentarios ofensivos o falsos.
- Validar cambios importantes.
- Corregir información duplicada.

## Administrador

Responsable general del sistema.

Puede:

- Gestionar usuarios.
- Gestionar lugares.
- Revisar estadísticas.
- Configurar categorías.
- Administrar moderadores.
- Gestionar políticas de seguridad y privacidad.

## Reglas de permisos

- Un visitante solo consulta.
- Un usuario registrado puede aportar.
- Un colaborador ayuda a validar.
- Un comercio solo administra su propia ficha.
- Un moderador revisa contenido.
- Un administrador gestiona todo el sistema.
