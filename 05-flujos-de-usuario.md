# Flujos de Usuario

## Flujo 1: Buscar un lugar accesible

1. El usuario abre la aplicación.
2. La app muestra el mapa y la ubicación actual.
3. El usuario escribe el nombre o categoría del lugar.
4. La app muestra resultados cercanos.
5. El usuario aplica filtros de accesibilidad.
6. Selecciona un lugar.
7. Revisa la ficha, fotos, valoraciones y comentarios.
8. Decide si ir al lugar o buscar otra alternativa.

## Flujo 2: Consultar una ruta accesible

1. El usuario indica origen y destino.
2. La app calcula opciones de ruta.
3. El usuario activa preferencias, como evitar escaleras o cuestas.
4. La app muestra rutas recomendadas.
5. Cada ruta indica distancia, tiempo aproximado y nivel de accesibilidad.
6. El usuario selecciona una ruta.
7. Durante el trayecto, la app puede mostrar avisos de obstáculos o reportes cercanos.

## Flujo 3: Valorar un lugar

1. El usuario entra en la ficha de un lugar.
2. Selecciona la opción de valorar.
3. La app muestra un formulario simple.
4. El usuario califica accesibilidad, trato, seguridad y experiencia general.
5. Puede añadir comentario y fotos.
6. Envía la valoración.
7. La app actualiza la puntuación del lugar.

## Flujo 4: Reportar un problema

1. El usuario detecta un obstáculo o problema.
2. Pulsa el botón de reportar.
3. La app toma la ubicación actual o permite elegirla en el mapa.
4. El usuario selecciona el tipo de problema.
5. Añade descripción y foto opcional.
6. Envía el reporte.
7. Otros usuarios pueden confirmar si el problema sigue activo.

## Flujo 5: Usar el botón SOS

1. El usuario pulsa el botón SOS.
2. La app muestra una confirmación rápida para evitar activaciones accidentales.
3. Si confirma, la app obtiene la ubicación actual.
4. Envía un mensaje al contacto de emergencia configurado.
5. Muestra opciones para llamar a emergencias o ver puntos de ayuda cercanos.
6. Guarda el evento como alerta SOS.

## Flujo 6: Configurar preferencias de accesibilidad

1. El usuario entra a su perfil.
2. Abre la sección de preferencias.
3. Selecciona las condiciones que quiere priorizar o evitar.
4. Guarda la configuración.
5. La app usa esas preferencias para filtrar lugares y rutas.

## Flujo 7: Confirmar información de otro usuario

1. El usuario ve una ficha o reporte.
2. La app pregunta si la información sigue siendo correcta.
3. El usuario confirma, corrige o reporta que está desactualizada.
4. La app registra la validación.
5. La confianza del dato aumenta o disminuye según las confirmaciones.
