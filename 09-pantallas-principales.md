# Pantallas Principales

## 1. Pantalla de inicio / mapa

Pantalla principal de la aplicación.

Debe incluir:

- Mapa.
- Ubicación actual.
- Barra de búsqueda.
- Botón de filtros.
- Botón SOS.
- Marcadores de lugares.
- Reportes cercanos.

## 2. Registro e inicio de sesión

Permite crear cuenta o entrar con una cuenta existente.

Debe incluir:

- Registro con correo o teléfono.
- Inicio de sesión.
- Recuperación de contraseña.
- Aceptación de términos y privacidad.

## 3. Perfil del usuario

Muestra y permite editar datos personales.

Debe incluir:

- Nombre.
- Foto opcional.
- Preferencias de accesibilidad.
- Contactos de emergencia.
- Lugares favoritos.
- Historial de aportes.

## 4. Configuración de accesibilidad

Pantalla para personalizar la experiencia.

Debe incluir:

- Evitar escaleras.
- Evitar cuestas.
- Priorizar rutas llanas.
- Mostrar solo lugares con baño accesible.
- Activar alto contraste.
- Tamaño de texto.
- Tipo de alertas.

## 5. Buscar lugar

Pantalla o panel para buscar lugares.

Debe incluir:

- Campo de búsqueda.
- Categorías.
- Filtros.
- Lista de resultados.
- Orden por cercanía, accesibilidad o valoración.

## 6. Detalle del lugar

Ficha completa de un lugar.

Debe incluir:

- Nombre y dirección.
- Fotos.
- Puntuación.
- Información de accesibilidad.
- Comentarios.
- Botón para valorar.
- Botón para reportar problema.
- Botón para guardar favorito.
- Botón para iniciar ruta.

## 7. Valorar lugar

Formulario para registrar experiencia.

Debe incluir:

- Puntuaciones.
- Preguntas de accesibilidad.
- Comentario.
- Subida de fotos.
- Confirmación antes de publicar.

## 8. Reportar problema

Pantalla para crear un reporte.

Debe incluir:

- Tipo de problema.
- Ubicación.
- Descripción.
- Foto opcional.
- Botón de enviar.

## 9. Ruta accesible

Pantalla que muestra una ruta recomendada.

Debe incluir:

- Mapa de ruta.
- Distancia.
- Tiempo aproximado.
- Nivel de accesibilidad.
- Advertencias.
- Tramos con escaleras, rampas o cuestas.
- Alternativas.

## 10. Transporte público

Pantalla para consultar líneas, paradas y accesibilidad.

Debe incluir:

- Línea o ruta.
- Paradas.
- Accesibilidad de vehículos.
- Ascensores o rampas.
- Reportes recientes.
- Valoraciones.

## 11. SOS

Pantalla o acción rápida para emergencia.

Debe incluir:

- Confirmación de activación.
- Contacto de emergencia.
- Ubicación actual.
- Mensaje que se enviará.
- Opción de llamar a emergencias.

## 12. Favoritos

Pantalla con lugares y rutas guardadas.

Debe incluir:

- Lugares favoritos.
- Rutas frecuentes.
- Paradas guardadas.
- Filtros y búsqueda interna.

## 13. Panel de moderación

Pantalla para revisar contenido reportado.

Debe incluir:

- Reportes pendientes.
- Comentarios denunciados.
- Fotos por revisar.
- Cambios sugeridos.
- Acciones de aprobar, rechazar o corregir.
