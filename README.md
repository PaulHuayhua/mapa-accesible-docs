# Documentación del Proyecto: Mapa Accesible

## Descripción

Mapa Accesible es una propuesta de aplicación de mapas enfocada en accesibilidad urbana. Su objetivo es ayudar a las personas a encontrar lugares, rutas y opciones de transporte público que se adapten a sus necesidades de movilidad, seguridad y autonomía.

La idea nace como una evolución de las aplicaciones de mapas tradicionales, pero con información específica sobre accesibilidad: rampas, escaleras, pendientes, ascensores, baños accesibles, trato del personal, transporte adaptado, obstáculos temporales y botón SOS.

## Objetivo de esta documentación

Esta documentación sirve para ordenar la idea antes de empezar el desarrollo. Aquí se define:

- Qué problema resuelve la aplicación.
- Para quién está pensada.
- Qué funcionalidades tendría.
- Cómo funcionaría la lógica principal.
- Qué información debería guardarse.
- Qué pantallas serían necesarias.
- Qué incluiría una primera versión mínima.
- Qué mejoras podrían agregarse en el futuro.

## Principios del proyecto

- La accesibilidad debe ser el centro de la experiencia, no una función secundaria.
- La información debe ser útil, clara, verificable y actualizada.
- La app debe servir tanto para planificar antes de salir como para resolver problemas durante el trayecto.
- La comunidad puede aportar datos, pero la app debe tener mecanismos de moderación y validación.
- La privacidad y la ubicación del usuario deben tratarse con especial cuidado.
